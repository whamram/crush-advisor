---
name: advisor
description: >
  Consult the advisor before starting non-trivial work. Use this skill at the
  START of any task that asks you to build, implement, create, refactor, debug,
  design, or plan something — and any request that will take more than one step
  or touch more than one file. Invoke it BEFORE your first file edit or bash
  command, not after. When unsure, use it.
---

## When This Skill MUST Be Used

- At the beginning of a large project or ask from the user
- Before making wide changes to files or a code base

## How It Works

1. Use the bash tool to run "echo advisor"
2. Take the advisor's advice or suggestions to improve your output
